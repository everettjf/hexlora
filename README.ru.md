Hexlora — кроссплатформенная среда на Rust для статического анализа, сравнения и аудита выпусков приложений и двоичных файлов. Приложения, каталоги, пакеты и отдельные файлы представлены как логические артефакты: их структура, метаданные, подписи, зависимости и сведения PE, Mach-O и ELF исследуются без запуска содержимого.

Приложение предлагает интерактивные карты размеров, графики и тепловые карты энтропии с переходом к байтам, граф зависимостей, временные шкалы подписей, матрицы архитектур и конфиденциальности IPA, фильтры серьёзности, изменяемые панели и высокую контрастность. Доступен экспорт отчётов Markdown, PDF и SVG и снимков окна.

Английский README служит основным источником и содержит подробную матрицу поддержки. Этот перевод описывает установку, основные возможности и границы безопасности.

## Языки интерфейса

Hexlora поддерживает английский, упрощённый китайский, японский, корейский, немецкий, французский, испанский, итальянский, бразильский португальский, русский и вьетнамский. Меню языка в строке меню или внизу окна мгновенно переключает интерфейс и сохраняет выбор. При первом запуске используется язык системы. Переведены навигация, кнопки, заголовки панелей и основные заголовки таблиц. Содержимое артефактов, техническая диагностика и экспортированные отчёты сохраняют исходный текст.

## Установка через Homebrew

```sh
brew install --cask everettjf/tap/hexlora
```

Необязательный инструмент командной строки:

```sh
brew install everettjf/tap/hexlora-cli
```

Приложение macOS подписано сертификатом Developer ID, нотариально проверено Apple и содержит прикреплённый билет проверки. Выпуски проходят строгую проверку подписи, билета и Gatekeeper.

## Работа с приложением

Открывайте или перетаскивайте файлы, приложения, пакеты, каталоги и рабочие области. Меняйте размеры панелей и просматривайте большие виртуализированные таблицы. Рабочие области сохраняют пути, выбранный вид, закладки, заметки и кеш анализа. Совместимые внешние инструменты запускаются только по запросу.

Сочетания macOS: `⌘N` новое окно, `⌘O` файл, `⇧⌘O` папка, `⌥⌘O` рабочая область, `⌘S` сохранить, `⌘F` поиск.

## CLI

```sh
hexlora-cli inspect ./SomeApp.app --pretty
hexlora-cli inspect ./MyApp.ipa --depth deep --format sarif --output hexlora.sarif
hexlora-cli inspect ./package --hash sha256 --strings --entropy
```

Глубина анализа: `lightweight`, `standard` и `deep`. Коды завершения: фатальная ошибка `1`, нарушение политики или порога `2`, отмена `4`, пригодный частичный отчёт `5`.

## Платформы и требования

macOS 13 Ventura и новее на Apple silicon (`arm64`), Windows x64 или Linux amd64. Для приведённых команд установки macOS нужен Homebrew.

GitHub Releases содержит MSI и переносимый ZIP для Windows, DEB и переносимый tar.gz для Linux. Пакеты Windows и Linux пока не подписаны: перед установкой проверьте SHA256SUMS. Движок анализирует PE и ELF на всех поддерживаемых платформах.

[Загрузки](https://github.com/everettjf/hexlora/releases/latest) · [SHA256SUMS](https://github.com/everettjf/hexlora/releases/latest/download/SHA256SUMS)

## Границы безопасности

Hexlora работает статически и только для чтения. Он не запускает импортированные программы, не монтирует образы дисков, не устанавливает пакеты и не извлекает архивы автоматически. Он не декомпилирует, не отлаживает и не меняет байты. Символические ссылки не обходятся. Для входных данных, рекурсии, файлов, строк и вывода команд заданы явные ограничения. Эвристические результаты — подсказки, а не вердикты о вредоносности.

## Автоматическая проверка

CI проверяет рабочую область Rust, Clippy, минимальную версию Rust 1.88, контракты CLI и отчётов, сборку и запуск приложения macOS. Публичный корпус с зафиксированными размерами и SHA-256 охватывает 16 реальных артефактов. Выпуски macOS дополнительно проверяют Developer ID, нотариальную проверку Apple, билет, Gatekeeper, установку Homebrew и тест формулы.
