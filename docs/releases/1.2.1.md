Hexlora 1.2.1 is a desktop usability release: nothing in a table is cut off or out of reach any more, and the Strings view lists everything it should.

**Tables**
- 64-bit addresses and offsets are always shown in full instead of ending in an ellipsis.
- Click any row to read every value in full, wrapped, with a Copy Row button.
- A table wider than its panel now shows a horizontal scrollbar, and **More columns →** in its heading jumps to the columns past the edge.
- Tables list up to 250,000 rows instead of 20,000.

**Strings**
- Fixed the Strings view dropping most of a file's strings. Extraction used to fill its limit with two- and three-byte noise; a 17 MB executable that showed 5,957 strings now shows 68,320.
- The view says so when a file has more strings than the limit.

**Easier to read**
- Search results lead with the file name and what matched; paths are relative to the opened artifact.
- Errors appear in their own strip with the whole message and a Dismiss button, instead of one clipped line in the status bar.
- Dependency graph nodes show the end of a library path, where the name is.
- The Artifact Tree no longer draws two triangles beside each folder, and a filtered tree keeps names readable.
- Details and inspector pages start at the top when you select another node.
- Chart labels no longer overlap, and the file type legend shows full category names.

**Corrections**
- An IPA's details show the application's bundle identifier, not that of an embedded resource bundle.
- Folders and application bundles show the size of their contents instead of `0 B`.
- Mach-O dependency lists no longer include a `self` entry.
