Hexlora 1.3.1 is a small fix release for the desktop app.

**Fixes**
- Output from an external tool (objdump, otool, nm, strings, codesign) is readable again when the Details panel is already full. It used to collapse to a sliver at the bottom of the panel that could not be scrolled into view.

**Documentation**
- The README now names **File → Scan with YARA Rule Folder** as its own menu item; `⇧⌘Y` chooses a single rule file.
