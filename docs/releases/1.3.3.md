Hexlora 1.3.3 makes the handoff to Hopper work.

**Fixes**
- **External Tools → Open in Hopper** now opens the file in Hopper. It used to report that Hopper had been launched while Hopper opened nothing.
- Launched from the Disassembly tab, Hopper jumps straight to the address you are reading, instead of leaving it on the clipboard.

The first time you use it, macOS asks once whether Hexlora may control Hopper; Hopper's launcher needs that to open a file.
